# Screenshot capture checklist

This directory is reserved for genuine screenshots captured from the running WhisperDrop application. Do not use mockups, generated interface images, or screenshots reconstructed from source.

Please capture these images from the released app and save them here as PNG files:

1. `main-window.png` — the main window with the model selector, file drop area, and export choices visible.
2. `transcription-complete.png` — a completed transcription showing the selected output formats and completion state. Use a non-private sample and avoid exposing private paths or transcript content.
3. `model-selection.png` — the model selector and download/import controls, without account names or unrelated windows.

Review images for personal names, private file paths, notifications, account details, and unrelated desktop content before adding them. Update the README screenshot section when the captures are present.
